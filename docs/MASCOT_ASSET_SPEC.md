# Learning guide asset specification

The current guide is an original neutral vector composition built from bundled icons and the character `字`; it has no third-party character, franchise, or copyrighted mascot dependency.

States: idle, happy, encourage, correct, incorrect-supportive, celebrate, thinking, empty-state.

If replacing it with art, provide owned/licensed SVG or PNG assets in light/dark variants, minimum 2x density, transparent background, no embedded text, and documented attribution/license.
