# English Statistics V7.2 — UX and Data Presentation

Zero review attempts are treated as insufficient evidence, not as a 0% score or a proficiency judgment. The empty state communicates that there is not enough review data. Redundant zero-value badges/subtitles and the unused XP/time spotlight are hidden until values exist. When attempts exist, the score is derived from existing real statistics; duration is formatted for readers and the spotlight can stack/wrap on narrow screens. Repeated data-isolation copy was removed so the progress and next action are easier to find.

The V7.2 presentation does not create sample series or alter the statistics repository/calculation. Populated screenshots use a clearly isolated UI preview fixture; they are not user records. The visual runner verifies empty/populated/dark states and narrow viewport/font stress. See the final manifest for case-level results.

Study coverage is distinct from review accuracy. Its redundant 0% badge is suppressed when nothing has been studied; the actual count remains visible. A real 0% accuracy result after recorded attempts remains valid and is covered separately by tests.
