# V5 vocabulary senses

Schema 36 adds `word_senses`, `word_sense_examples`, `word_collocations`. Existing vocabulary IDs, meanings, pronunciation variants and examples remain unchanged. A sense is identified by `(vocabulary_id,sense_id)`, with its own POS, Vietnamese/English definitions, numeric pinyin, usage, source and review status. Examples link to existing shared sentences; collocations link to a specific sense.

No automatic split/translation/conversion is treated as verified. DRAFT is the default; non-draft senses require explicit reviewer/time. No mass corpus edits before the V5 gap audit. Verified publication also needs independently verified source/license; database status alone is not evidence.

This is an additive foundation, not a claim that 11,330 entries already have reviewed senses or collocations. Human editorial review and learner-facing sense selection remain necessary.
