# Hanzi stroke data attribution

The bundled HSK 1–9 and supplemental stroke paths in `hsk12-strokes.json` and
the eight lazy runtime files `stroke-shard-0.json` through `stroke-shard-7.json` are generated from
`hanzi-writer-data` 2.0.1, derived from the Make Me A Hanzi project.

The data is distributed under the Arphic Public License. The complete license
is stored beside this file in `ARPHICPL.TXT`.

Source: https://github.com/chanind/hanzi-writer-data

`stroke-coverage.json` records unsupported characters. The generator never
substitutes simplified paths for a different traditional character.
